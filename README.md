# Wayfare

An Android trip planner. Save places, arrange them into days, and take the lot
with you — it keeps working when the signal doesn't.

It began as an app for one family's week in Scotland, and everything specific
to that trip has since been taken out. What is left works anywhere: you tell it
where you're going and who's coming, and the rest follows from that.

The app has six tabs:

- **Today** — the day's stops in time order, with the next one flagged, walking
  times between them, and the forecast at the top
- **Kids** — the places they'll actually enjoy, and searches worded for the age
  of the child you have
- **Itinerary** — day-by-day plan; drop saved places into days and give them times
- **Picks** — everything you've saved, grouped by area, filtered by All / To do /
  Eat, plus search and "explore around a place"
- **Budget** — cost breakdown and running total
- **Tips** — walking-with-a-4-year-old advice, crowd-avoidance, safety notes, and
  a tappable packing checklist

## What needs signal, and what doesn't

Your places, the plan, notes, the budget and the packing list are stored on the
device and work with no connection at all. Forecasts are cached, so the last one
fetched stays readable offline.

Searching, exploring, and refreshing the weather need a connection. So do map
tiles the first time you look at them — **Settings → Offline maps** downloads the
area around your saved places so maps still draw where there's no signal. The app
shows a banner when it's offline rather than letting each feature fail in its own
words.

Nothing is stored anywhere but the phone, so **Settings → Backup** exports a file
worth keeping; the app tells you how long it's been.

## Getting the APK

Every push to this repo builds a debug APK automatically via GitHub Actions:

1. Go to the repo's **Actions** tab → **Build Android APK** → latest run.
2. Download the `wayfare-debug-apk` artifact (a zip containing `app-debug.apk`).
3. Copy the APK to your Android phone and open it to install (you'll need to allow "install from unknown sources" for the app you use to open it, since it isn't from the Play Store).

## Project structure

- `www/` — the app itself (plain HTML/CSS/JS, no build step; Leaflet is vendored, everything else is fetched at runtime)
- `www/js/data.js` — all trip content (itinerary, places, budget, tips, packing list) — edit this file to change the plan
- `android/` — native Android project generated by [Capacitor](https://capacitorjs.com/), which wraps `www/` in a WebView
- `.github/workflows/build-apk.yml` — CI that builds the debug APK on every push

## Building locally

Requires Node.js and Android SDK / Android Studio.

```bash
npm install
npx cap sync android
cd android
./gradlew assembleDebug
# APK at android/app/build/outputs/apk/debug/app-debug.apk
```

To edit the trip content, change `www/js/data.js` and re-run `npx cap sync android` before rebuilding.
